## Description (4000)

```
fjs go is the development client for the ufjs framework, for developers who build mobile apps with Vue 3 and TypeScript.

Run `fjs dev` in your ufjs project, scan the QR code it prints with fjs go, and your project runs on your phone with native UI. Save a file and the page reloads — no rebuild, no reinstall.

THREE WAYS TO CONNECT
• Scan the QR code printed by fjs dev
• Nearby servers: projects on the same Wi-Fi show up automatically
• Enter an address, or paste the URL fjs dev prints

ONLINE DEMO
No development setup yet? Tap "在线演示" (Online Demo) on the home screen to explore the official sample project:
• 60+ built-in component and API samples
• ECharts and F2 charts, Canvas 2D drawing
• WebGL, three.js and PixiJS scenes and mini games

BUILT FOR DEBUGGING
• Your project runs full screen, exactly as it will ship; developer tools sit behind a draggable floating button
• Reload, read console logs, or disconnect in one tap
• A red badge on the button flags JavaScript errors as they happen
• Recent servers are remembered
• Light and dark mode, iPhone and iPad

NOTE
fjs go is a developer tool. It runs the project served by fjs dev on your own computer, or the official sample project. Apps you ship bundle their code and do not depend on fjs go.
The interface is in Simplified Chinese. No sign-in, no personal data collected.
```
