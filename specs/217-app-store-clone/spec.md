# Spec: app-store-clone —— iOS App Store 交互与样式复刻示例

- **ID**: 217-app-store-clone
- **状态**: in-progress
- **日期**: 2026-10-15
- **来源**: iPhone 镜像（iOS 26）里实机浏览 App Store 的 Today / 游戏 / App /
  Arcade / 搜索 / 应用详情，逐页截图采集的布局、配色与手势。

## 1. 要解决什么

仓库里的示例（hello-fjs 的组件画廊、vant/nutui 页）都是"组件演示"，缺一个**整 app
级**的、以 iOS 原生 app 为对标的复刻样例：悬浮玻璃 tab 栏、大标题页、横向分页卡、
卡片按下缩放、卡片展开成全屏详情这一套，是检验 ufjs 能否撑起"原生观感"的最好标尺。
现在没有这样的样例，也就没有地方暴露这些组合场景里的两端差异（玻璃面 + 滚动 +
共享元素转场 + 按下态同时出现时的表现）。

## 2. 不做什么（Non-goals）

- **不抓取、不内嵌 Apple 的真实素材**（应用图标、封面、截图、Arcade 图）。全部用
  本地占位：渐变 / emoji / SVG；应用名与文案用虚构或通用词，不用真实商标。
- 不做真实商店能力：下载安装、账号、内购、搜索联网、榜单数据。「获取 / 打开 /
  云下载」只切换本地状态。
- 不做 Today 的全部卡片种类（只做采集到的 3 种：大故事卡、广告卡、列表卡）。
- 不新增内置标签、不改 op 协议 / natives / 事件表（宪法 II、VII）；发现缺口时
  先在示例里用既有标签 + 模块包（`@ufjs/liquidglass`）解决，解决不了的列入
  §7 另开 spec，**不在本 spec 里下 Dart**。
- 不做 iPad / 横屏布局，不做深色模式（采集只有浅色；见 §7 待澄清）。
- 不做 mp（小程序）端适配；本示例目标是 Flutter + Web 两端（宪法 I）。
- 不对齐 iOS 的 SF 字体 / 动态字体；用系统默认字体，字号字重取采集值。

## 3. 用户可见的行为

新示例工程 `examples/app-store-clone`（结构照 `examples/racing`：`fjs dev` 跑
Flutter，`vite` 跑 Web，同一份源码）。

### 3.1 全局框架

- 5 个 tab：**Today / 游戏 / App / Arcade / 搜索**，走全局 tabBar 机制
  （`createFjsApp({ tabBar })`，specs/210）；tab 栏用 `@ufjs/liquidglass` 的
  `GlassTabBar` 风格（specs/212）：悬浮胶囊、不贴边、半透明，选中项有胶囊高亮
  + 蓝色（采集值：高亮胶囊明显深于底，图标/文字 `#0A84FF` 一类系统蓝）。
- 每个 tab 页：左对齐大标题（≈34px 粗体）+ 右上圆形头像（渐变占位 + 文字
  缩写）；内容滚动时大标题随内容一起滚走（采集里没有吸顶小标题，不做）。
- 页面底部留出 tab 栏高度的 padding，内容可从玻璃栏下方透出。

### 3.2 Today

```vue
<!-- 三种卡片，竖向排列，卡片间距 ≈ 16px，左右边距 ≈ 20px -->
<StoryCard />   <!-- 大故事卡 -->
<AdCard />      <!-- 广告卡 -->
<ListCard />    <!-- 「时下热门」列表卡 -->
```

- **大故事卡**：圆角 ≈ 20px、柔和阴影；全幅媒体（占位渐变 + 大 emoji）；下半部渐变
  遮罩，依次是小标题（小字、半透明白）、大标题（≈ 28px 粗体白）、副标题；卡片
  底部一条**玻璃条**（`<glass-surface>`）内含应用图标、名称、副标题与右侧
  「获取」胶囊按钮，按钮下有「App 内购买」小字。
- **广告卡**：灰/模糊背景、居中大圆角图标、左下「广告」蓝底小标签 + 名称 +
  副标题、右侧「打开」胶囊。
- **列表卡**：白底圆角卡，上有小标题「时下热门」，行内容与 §3.4 列表行同。
- **按下态**：按住卡片整体缩小到 ≈ 0.96，松手回弹（`transition: transform`）。
- **点开**：点故事卡 / 列表卡 → 卡片以共享元素方式展开为**全屏详情**
  （复用 hello-fjs 的 `hero.ts` 飞行盒思路，spec 101）；详情右上角悬浮圆形
  「✕」玻璃按钮，大标题随滚动钻到按钮下面；点 ✕ 回飞收起。

### 3.3 游戏 / App 页（同一个页面骨架，数据不同）

- 顶部一排**可横滑的分类胶囊**（图标 + 文字，白底、高 ≈ 36px、全圆角），超出
  屏宽可滚动，右侧露出半个胶囊提示可滑。
- **精选大图卡**横向分页（`swiper`，露出下一张的边缘）：卡片上方蓝色小标签 +
  大标题 + 灰色副标题，下面是圆角大图；「App」页的卡可带应用条。
- **带 `›` 的分区标题**（如「What We're Playing ›」「让你爱不释手的 App ›」），
  点击无动作或跳详情（见 §7）。
- **列表**：每 3 行为一组，**组与组横向分页**（右侧露出下一组边缘）；行由图标
  （≈ 60px 圆角方块）、名称、副标题、右侧按钮组成，行间 0.5px 分割线（左侧缩进
  到图标右边）。

### 3.4 列表行与按钮状态（全局复用）

| 状态 | 右侧控件 |
|---|---|
| 未安装 | 浅灰底（`#F2F2F7` 一类）蓝字「获取」胶囊 + 下方「App 内购买」小字 |
| 已安装 | 同款胶囊，文字「打开」 |
| 云端已购 | 蓝色云下载图标（SVG），无胶囊 |

点「获取」→ 短暂进入"下载中"（圆环进度）→ 变「打开」，纯本地 state，用来验证
状态切换与 transition 在两端一致。

### 3.5 Arcade

- 顶部整屏渐变英雄区：居中白色大字 + 蓝色实心大胶囊「接受优惠」+ 下方灰色小字
  价格说明；英雄区向下滚动后接分类胶囊行与「Try Before Subscribing」列表。

### 3.6 搜索

- 大标题「搜索」+ 圆角搜索框（占位文案「游戏、App、故事等」，左放大镜图标）；
  聚焦时可输入，输入时下方列表按名称**本地过滤**。
- 「为你推荐」：3 行列表，横向分页。
- 「浏览」：两列渐变分类卡（圆角 ≈ 16px，左下白字标题，右上插画占位），点击
  无动作或进榜单（见 §7）。

### 3.7 应用详情页

- 顶部大封面（占位渐变），左上**红色圆形返回按钮**、右上**圆形分享按钮**（均为
  玻璃/半透明圆）；
- 封面下方白色圆角面板上移压住封面（≈ 20px 圆角）：大圆角图标（≈ 100px）+ 标题
  （粗体多行）+ 开发者 + 下载/云图标按钮；
- **信息栏**：横向滚动、等宽分栏、竖向分割线——「评分 4.7 + 星」「获奖 编辑精选」
  「年龄分级 13+」「排名 #n」；
- 「新功能 ›」+ 版本号 / 时间 + 更新文案；「预览」+ 横滑截图（占位）。

## 4. 两端约定（宪法 I）

| | Flutter | Web |
|---|---|---|
| 玻璃面（tab 栏、卡片底条、✕ / 返回按钮） | `<glass-surface>`，`liquid_glass_widgets` | 同标签，`backdrop-filter` |
| 横滑 / 分页 | `scroll-view scroll-x`、`swiper`（PageView） | 同标签 |
| 按下缩放 | `:active` / `hover-class` + `transform: scale` + `transition` | 同 |
| 卡片展开 | `hero.ts` 飞行盒：`fjs.ui.rect` 测距 + `position: fixed` + 几何 `transition` | `getBoundingClientRect` |
| 渐变 / 阴影 / 圆角 | `linear-gradient` / `box-shadow` / `border-radius` ✅ | 同 |
| 事件载荷 | 一律字符串（`@change` 为真实索引串） | 同 |
| 已知差异 | 折射只保证"有无"，blur / tint / radius 一致（`css-compat.md` 玻璃节）；`transition-delay` 在 App 端对尺寸类不生效 | — |

不一致处在本示例落地时登记到 `docs/css-compat.md` / `docs/web.md` 的差异表。

## 6. 验收标准

1. `pnpm install` 后 `pnpm --filter app-store-clone run typecheck` 通过。
2. `pnpm run typecheck`（全 workspace）与 `pnpm test` 不因新增示例而变红。
3. `pnpm --filter app-store-clone run dev:web` 起来后，5 个 tab 可切换，每个
   tab 的页面骨架与 §3 一致（逐页对照 iPhone 镜像采集截图目测）。
4. `fjs dev` + `fjs run ios`（或 android）上同样 5 个 tab 可切换，与 web 目测
   一致；差异登记在文档里。
5. Today：长按故事卡可见缩小回弹；点击展开为全屏详情，✕ 回飞收起；列表卡点开
   同理。
6. 游戏 / App：分类胶囊可横滑；精选卡 `swiper` 可翻页且露出下一张；列表每 3 行
   一组可横向翻页。
7. 列表行「获取」→ 下载中 → 「打开」状态切换两端一致；「云端已购」行显示云图标。
8. 搜索：输入关键词，推荐列表本地过滤；清空恢复。
9. 详情页：返回键回上一页；信息栏可横滑；预览可横滑；封面压面板层次正确。
10. `fjs build --release`（Flutter）与 `vite build`（Web）都能产出；产物里**没有**
    任何 Apple 真实素材文件。
11. 代码里不出现 `gc()` 调用（见项目记忆「gc() 仅限调试」）。
